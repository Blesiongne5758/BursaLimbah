## 🎯 User Journey Summary

### Journey 1: New User Registration
```
Landing → Click "Daftar Gratis" → Register Page → Fill Form → 
Success → Dashboard
```

### Journey 2: Existing User Login
```
Landing → Click "Masuk" → Login Page → Enter Credentials → 
Success → Dashboard
```

### Journey 3: Browse & Purchase
```
Landing → Click "Jelajahi Marketplace" → Marketplace Page → 
Filter/Search → Click Listing → Detail Page → Click "Negosiasi" → 
Payment Page → Review → Payment → Success → Dashboard
```

### Journey 4: AI Assistant
```
Any Page → Click Chat Button → Chat Opens → Type Question → 
AI Response → Continue Conversation
```
